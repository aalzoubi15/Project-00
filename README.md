# Discovery Web Piscine

## About

This project is part of Project 00 and focuses on Linux, Git, and GitHub.

The project introduces basic terminal commands, file manipulation,
Git version control, GitHub repositories, and SSH authentication.

## Linux

Linux provides a command-line environment for working with files,
directories, and development tools.

## Git

Git is a version control system used to track changes in a project.

It allows developers to save different versions of their work,
review previous changes, and work safely on a project.

## GitHub

GitHub is a platform for hosting Git repositories online.

It allows developers to store their projects remotely and collaborate
with other developers.

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes.

If I make a mistake, I can look at previous commits and recover an
older version of my work.

Git also makes collaboration easier because multiple developers can
work on the same project and share their changes.

It also gives me a safe way to experiment with changes without
losing the original version of my code.
