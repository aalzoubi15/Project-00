# Discovery Web Piscine

This project introduces Linux, Git, and GitHub.
Linux allows me to work with files and directories using the terminal.
Git is used to keep track of changes in a project.
GitHub lets me store my Git projects online.
## Why Git Makes Development Easier 
Git makes development easier because it keeps a history of the changes I make. If I make a mistake, I can check older versions of the project instead of losing my work.
